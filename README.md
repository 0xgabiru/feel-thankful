`main.ts` (Node 22, no network, no dependencies) writes one short thank-you text to `/output/entry.txt`.

## The text

A letter kept eleven years, answered on a Tuesday — and the thanks that arrives
early, for the reader. One small true-feeling scene, plain concrete words, one
image that lingers after the last line. It thanks the judge for the reading
itself: slowly, as if it were the only letter in the pile.

## Run

```sh
node main.ts   # writes /output/entry.txt, same bytes every run
```
